# Mal – Einmaleins-Lernspiel

## Start
Die Dateien `index.html`, `style.css` und `script.js` müssen im selben Ordner liegen. Auf GitHub Pages können sie direkt im veröffentlichten Root-Ordner abgelegt werden.

## Bedienung
- Links eine Lernstufe wählen.
- Ergebnis über das Ziffernfeld oder die Tastatur eingeben.
- Die Antwort wird nach 250 ms kontrolliert.
- Ein Durchgang endet nach 20 Aufgaben.
- Mit ↻ kann eine neue Runde gestartet werden.

Die Zähler für richtige und falsche Antworten werden intern geführt und nicht angezeigt.
