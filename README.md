# Mal – Einmaleins-Lernspiel

## Start
Die Dateien `index.html`, `style.css` und `script.js` müssen im selben Ordner liegen. Auf GitHub Pages können sie direkt im veröffentlichten Root-Ordner abgelegt werden.

Diese Fassung ist identisch mit dem Mal-Spiel in DENKAVO (`public/mal`). Eigenständig werden keine
Lernereignisse gesendet; der Haus-Knopf ist ausgegraut.

## Bedienung
- Oben eine Stufe wählen (Kern, Kern Mix, 3er, 4er, 6er, 8er, 7er, 9er, Mal Mix).
- Ergebnis über das Ziffernfeld oder die Tastatur eingeben; die Antwort wird nach 1 s kontrolliert.
- Fortschrittspunkte über der Rechnung: ein Punkt je erledigter Aufgabe.
- Knopf mit Punktefeld: Animation ein/aus (Hilfe bei Fehlern läuft trotzdem).
- Falsche Antwort: Hilfsanimation, danach ist das Ergebnisfeld leer; dieselbe Rechnung bleibt, bis sie richtig ist.
  Sie kommt nach 2 weiteren Aufgaben noch einmal (zählt dann nicht mehr).
- Ein Durchgang endet nach 20 Aufgaben. „Ende“ beendet die Runde vorzeitig und zeigt Ergebnis und Zeit.
- Additive Rechenwege (z. B. 7·b = 5·b + 2·b, 8·7 = 8·5 + 8·2): beide Kernaufgaben rot eingerahmt.
